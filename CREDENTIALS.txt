--------------------------------------------------------------------------------
 1. LOCAL TOOLS TO INSTALL (one-time)
--------------------------------------------------------------------------------

[ ] Docker Desktop (must be RUNNING — green whale icon)
      Why: `supabase start` needs Docker to boot local Postgres + Auth + Realtime + Storage.
      Install: https://www.docker.com/products/docker-desktop/

[ ] Supabase CLI
      Why: local Supabase stack, Prisma migrations, RLS tests.
      Install: brew install supabase/tap/supabase
      Then:   cd /Users/divyanshkoolwal/Desktop/ednacharge && supabase start
              (prints the anon key + service role key — save them; you'll paste into .env below)

[ ] Stripe CLI
      Why: forwards Stripe test webhooks into the local api.
      Install: brew install stripe/stripe-cli/stripe
      Then:   stripe login
              stripe listen --forward-to localhost:3000/webhooks/stripe
              (prints a `whsec_…` secret — save it; paste as STRIPE_WEBHOOK_SECRET below)

[ ] Xcode (for iOS simulator) OR Android Studio (for Android emulator)
      Why: to actually open `apps/mobile` on a phone.

[LATER] Maestro (for E2E yaml in PRD §20)
      Install: curl -Ls "https://get.maestro.mobile.dev" | bash

--------------------------------------------------------------------------------
 3. RUN ORDER (once all secrets above are filled in)
--------------------------------------------------------------------------------

Terminal 1 — boot supporting infra:
    /opt/homebrew/bin/redis-server --daemonize yes --logfile /tmp/redis.log
    supabase start

Terminal 2 — apply DB schema + RLS:
    cd /Users/divyanshkoolwal/Desktop/ednacharge
    pnpm -F @edna/db migrate
    pnpm -F @edna/db rls:apply
    pnpm -F @edna/db seed              # 20 Tri-Valley chargers

Terminal 3 — Stripe webhook forwarding:
    stripe listen --forward-to localhost:3000/webhooks/stripe

Terminal 4 — the app:
    cd /Users/divyanshkoolwal/Desktop/ednacharge
    pnpm dev                           # boots api + csms + worker + mobile
    # in another tab:
    pnpm demo:loop                     # must exit 0

Mobile:
    cd apps/mobile
    pnpm ios          # or: pnpm android

Phase gates (run after their prereqs are provisioned):
    pnpm sentry:smoke                  # needs all 4 Sentry DSNs
    pnpm sim --charger sim-001 --session 30m   # CSMS + simulator smoke
    pnpm chaos                         # 5× happy-path loop
